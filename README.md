# 伴伴 · 宠物模拟实验室

一个用于智能玩具教学与平台接入验证的可运行项目。React 构建终端界面，Three.js 绘制可交互三维小狗，Node.js + WebSocket 提供本地演示平台。无需模型密钥或硬件。

## 启动

需要 Node.js 22.12+（本项目在 Node.js 24 下验证）。

```powershell
npm install
npm run dev
```

打开 http://127.0.0.1:5173 。终端开发服务器为 5173 端口，演示平台为 8787 端口。两者仅监听本机；`Ctrl+C` 结束开发进程。

生产构建与本机运行：

```powershell
npm run build
npm start
```

打开 http://127.0.0.1:8787 。编译后的前端和 WebSocket 由同一个服务提供。

## 已实现

- 三维小狗：转动视角、缩放、三种毛色、呼吸与眨眼，点击身体触发摸头。
- 互动：摸头、合成叫声、喂零食、玩小球、坐下、休息与唤醒。
- 本地电源和声音开关、视角复位。离线仍可执行本地动作。
- 文字聊天：通过 WebSocket 获取规则回复，支持动作指令。
- 浏览器语音合成；可用时提供语音转文字，结果由用户确认发送。
- 摄像头授权、拍摄、上传图片、预览、删除；关闭窗口/拍摄完成时停止视频流。
- 本地演示记忆：提取“我叫…”和“我喜欢…”，服务重启后保留，支持逐条或全部删除。
- 设备事件、连接状态、自动重连、配置平台地址与设备编号、模拟电量遥测。
- 桌面和手机布局、键盘操作与减少动态效果偏好。

## 演示边界

聊天**不是大模型对话**，是 `server/platform.mjs` 中可查看的规则。它不会识别照片，也不会推断用户事实。记忆是按设备编号区分的名字/喜好记录，不是完整的账户、身份认证或长期记忆产品。

照片仅在浏览器当前页面保存；只发送尺寸与 `contentTransferred: false`，不发送图片内容。刷新页面即丢失。聊天记录和事件日志也只在当前页面保留。演示记忆保存在 `data/memories.json`，不纳入源码管理。

语音识别支持和中文语音合成音色取决于浏览器及系统。语音识别可能使用浏览器厂商在线服务；无法识别时使用文字输入。麦克风和摄像头需在 localhost 或 HTTPS 环境运行。犬吠为 Web Audio 合成音效。

电量是手动设置的模拟遥测，不是电脑真实电量。终端和平台的职责是分开的：三维动画和硬件模拟在客户端，规则回复和记忆在服务端。

本项目用于**本机单用户教学演示**，未提供鉴权、租户隔离、家长控制或生产级存储；设备编号本身不是身份凭证。部署到外部网络前需要增加这些平台能力。切换到同一设备编号会读取该设备的演示记忆。

## 接入自己的平台

点击“设备设置”，输入兼容本协议的 `ws://` 或 `wss://` 地址。HTTPS 页面需要 WSS。默认地址随当前页面来源自动生成。

参见 [设备协议](docs/device-protocol.md)。真实玩具以后可以复用相同事件与指令；厂商适配层将动作映射到扬声器、舵机、LED 等执行器。

## 目录

| 文件                      | 职责                                   |
| ------------------------- | -------------------------------------- |
| `src/PetScene.jsx`        | 三维宠物模型与动作，不含记忆逻辑       |
| `src/device.js`           | WebSocket 设备协议、重连、合成犬吠     |
| `src/App.jsx`             | 互动界面、浏览器感知设备、相机生命周期 |
| `server/platform.mjs`     | 可替换的演示服务、规则回复和持久化记忆 |
| `docs/device-protocol.md` | 终端接入协议与能力说明                 |
| `tests/`                  | 协议、持久化与浏览器交互验证           |

## 验证

```powershell
npm test
npm run build
# 先保持 npm run dev 运行，再执行：
npm run test:ui
```

浏览器测试默认使用已安装的 Chrome。可设置 `BROWSER_CHANNEL=msedge` 使用 Edge；`APP_URL` 可指定测试地址。测试注入受控的 Canvas 视频流，验证拍摄、重复开启、关闭时停止视频流以及权限被拒绝的处理，不读取真实相机；真实硬件与语音识别仍需人工授权体验。截图保存在 `test-results/`。浏览器测试使用 `browser-test` 设备编号并清理其演示记忆。
